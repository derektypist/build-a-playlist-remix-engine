# Build a Playlist Remix Engine

Create a single remix playlist from multiple playlists submitted by listeners.

## Technologies

Uses JavaScript.

## Deployment

Copy `script.js` into the text editor of your choice.  If using terminal, use the command `node script.js` to run the code.
